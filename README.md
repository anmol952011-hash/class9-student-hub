# 📚 Class 9 Hub — AI Study Companion

An AI-powered study assistant designed specifically for Class 9 and 10 students. It helps students summarize chapters, generate mock tests, and get instant answers to academic questions.

🔗 **Live Demo:** https://class9-student-hub-flame.vercel.app/

## ✨ Features

- **📝 Chapter Summariser:** Paste any chapter text and get an instant, easy-to-understand bulleted summary.
- **📋 Mock Test Generator:** Enter a topic and get a practice test with 5 MCQs and 2 short answer questions.
- **❓ Ask AI:** A strict academic tutor that only answers Class 9/10 syllabus questions (powered by Groq).
- **👤 User Authentication:** Secure signup and login system to track questions asked.
- **📚 NCERT Library:** Quick links to official NCERT textbooks.

## 🛠️ Tech Stack

- **Backend:** Python, Flask
- **Frontend:** HTML, CSS, Vanilla JavaScript
- **AI Integration:** OpenAI SDK (via Groq API)
- **Deployment:** Vercel
- **Security:** Flask-Limiter (Rate limiting), Flask-Talisman (HTTPS enforcement), Werkzeug (Password hashing)
